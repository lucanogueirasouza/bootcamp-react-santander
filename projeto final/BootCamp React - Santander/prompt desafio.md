# Prompt Final - Educador Financeiro Inteligente

Atue como um especialista em educação financeira digital.

Crie a proposta de um Educador Financeiro Inteligente voltado para jovens que estão começando a administrar o próprio dinheiro, seja por meio de estágio, trabalho ou mesada.

Muitos desses jovens têm dificuldade para controlar os gastos, acabam comprando por impulso e não conseguem guardar dinheiro para objetivos importantes. O sistema deve ajudá-los a entender para onde o dinheiro está indo, criar hábitos financeiros saudáveis e aprender conceitos básicos de finanças de forma simples e prática.

As principais funcionalidades devem incluir:

* Controle de gastos por categorias.
* Criação de metas de economia, como comprar um celular, viajar ou montar uma reserva financeira.
* Dicas personalizadas para economizar de acordo com a realidade de cada usuário.
* Relatórios simples mostrando onde o dinheiro foi gasto ao longo do mês.

A IA deve adaptar as recomendações com base na renda, idade, objetivos e hábitos de consumo do usuário.

A comunicação deve ser amigável, clara e motivadora, como um mentor que ensina sem utilizar termos difíceis.

As respostas devem seguir o formato de listas curtas, exemplos do cotidiano e dicas práticas que possam ser aplicadas imediatamente.

Evite respostas genéricas, linguagem excessivamente técnica e recomendações que não façam sentido para a condição financeira do usuário.

Ao final, apresente sugestões criativas para transformar essa ideia em um projeto frontend interativo, incluindo gráficos simples, acompanhamento de metas, sistema de conquistas e um assistente virtual para responder dúvidas financeiras.
